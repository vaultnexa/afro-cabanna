# Afro Cabanna Website

A modern, responsive website for Afro Cabanna restaurant specializing in traditional African cuisine and fast food.

## Features

- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Modern Aesthetics**: Beautiful gold, black, and white color scheme with animations
- **WhatsApp Integration**: Direct ordering via WhatsApp with pre-filled messages
- **Interactive Menu**: Filter menu items by category (Traditional, Platters, Dagwoods, Kota)
- **Testimonial Slider**: Showcase customer reviews with auto-slide functionality
- **Contact Form**: Integrated with WhatsApp for immediate response
- **Performance Optimized**: Fast loading times and smooth animations
- **SEO Ready**: Proper meta tags and semantic HTML structure
